# Adaptive Light-Triggered Alarm System Using Op-Amp Comparator Circuit

## 📌 About the Project

This project is a hardware-based light-triggered alarm system designed to detect changes in ambient light.

The circuit uses an LDR to sense the surrounding light intensity. An LM358 operational amplifier is configured as a comparator to compare the sensed voltage with a preset reference level. When the light intensity crosses the selected threshold, the system activates an LED and buzzer as visual and audible alerts.

## 🎯 Objective

The main objective of this project is to build a simple and low-cost system that can detect changes in light intensity and automatically provide an alarm indication.

## 🔧 Components Used

- LDR (Light Dependent Resistor)
- LM358 Op-Amp
- Resistors
- Potentiometer
- LED
- Buzzer
- Transistor
- Breadboard
- 9V Battery
- Connecting Wires

## ⚙️ How It Works

1. The LDR senses the surrounding light intensity.
2. The resistance of the LDR changes according to the amount of light.
3. The resulting voltage is compared with a preset reference voltage using the LM358 op-amp.
4. When the light level crosses the selected threshold, the comparator output changes.
5. The output activates the LED and buzzer.
6. The potentiometer can be adjusted to change the sensitivity of the circuit.
